# غوار الأصلية - إدارة المصنع

نسخة Flutter عملية كأساس للمشروع.

## الدخول الأولي
- اسم المستخدم: `admin`
- كلمة المرور: `Ghawar@2026`
- غيّر كلمة المرور فوراً من: المزيد > إعدادات المدير.

## التسلسل
الرئيسية > القسم > خطوط الإنتاج > خط الإنتاج > التفاصيل.

## المضمن
الأقسام وخطوط الإنتاج، صلاحيات حسب المسؤول والقسم، إضافة قسم/خط/مسؤول، المستودعات،
الأصناف، المواد الخام، الإعدادات، الدعم الفني، سجل الدخول، المشاركة وواتساب، إعداد الطابعات وBluetooth/Wi-Fi.

## مهم للإنتاج
هذه نسخة محلية أولية. قبل نشرها فعلياً على Google Play يلزم Backend آمن للمستخدمين والصلاحيات،
تخزين كلمات المرور بشكل مشفر/مجزأ على الخادم، توقيع إصدار، سياسة خصوصية، وإكمال تكامل موديل الطابعة المحدد.
