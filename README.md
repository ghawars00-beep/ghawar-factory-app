# Ghawar Factory App — غوار الأصلية

نسخة تجريبية من تطبيق إدارة مصنع غوار الأصلية مبنية بـ Flutter.

## أقسام الإنتاج الحالية
- السمبوسة المحشية
- رقائق السمبوسة
- الكنافة
- خبز المرقوق
- القرصان
- اللحوح

## بناء APK عبر Codemagic
المشروع يحتوي على `codemagic.yaml`. عند تشغيل workflow باسم **Ghawar Factory Android APK** يقوم Codemagic بإنشاء ملفات Android المطلوبة ثم بناء `app-release.apk` تلقائياً.
